# Security policy

Report suspected vulnerabilities privately through the repository host's security-reporting feature; do not include sensitive material in public issues.

The bearer secret authorizes all three remote task tools. Store it only in a private configuration file, use a distinct high-entropy value generated by the operator, and replace it after suspected exposure. Keep the state directory private. Bind the process to loopback and terminate HTTPS in an authenticated reverse proxy.

The queue is least privilege by design: producers create bounded tasks on their configured route, and clients can only claim or terminally update their current lease. Public-reference validation is syntactic, not a trust decision. Treat all fetched material and every task result as untrusted data.
